## [0.3.0] - 2026-10-14

First public version.

### Added

- Channels (500), *Common*, *Selcall* and *Telephone* settings, programmable keys, antenna tuner memory.
- Read/write the radio through the SVC-1200 cable, with CE42's safe write sequence.
- Byte-compatible `.C42` files; CSV import/export of channels.
- Simulated radio for training and tests.
- User interface in Português, English, Español and Русский.
- Desktop program for Windows (installer and portable), macOS (Apple Silicon and Intel) and
  Linux (AppImage and `.deb`, x64 and arm64).
- Web app (Chrome/Edge, Web Serial) published on GitHub Pages.
